Folder Structure

1. node-modules contain the code for all the packages that we are using.
2. package.json contains the packages that the code is dependent on so making it like a chain.
3. package-lock.json contains the chain of dependent packages. (we don't need to make changes in this, it auto updates)

1. write in terminal git init -y creates package.json and we have initiated node.js appn 
2. to create a server using express package, so install express using npm i express.
3. now create a file server.js

server.js

const express = require('express');

const app = express()   // like function call , server is created , server instance is created


app.get("/", (req,res) => {

    res.send("Hello World")
})

app.get("/about", (req,res) => {
    res.send("About Page")
})



app.listen(3000)   // server is started  , 3000 is port no

Types of API
REST API- (Representational State Transfer Application Programming Interface)
It lets different software systems communicate over the web using standard HTTP methods

Common HTTP Methods (CRUD Operations)

• GET: Retrieve a resource (Read), server se data fetch karna ho
• POST: Create a new resource (Create), server par data send karna ho
• PUT / PATCH: Update an existing resource (Update), server par data already hai and usko update karna hai
• DELETE: Remove a resource (Delete), server par data hai usko delete karna hai
